# Agent Studio · 首版验收范围

用户确认：Godot 2D；RPGMaker 式俯视像素工作室；真实 Codex / subagent 调度。第一版必须包含扩建、布置、换装、技能配置，不能以后续版本代替。

- 房间：添加、调整尺寸、连接门、保存恢复；布局改变后保持可通行。
- 家具：网格摆放、选中、移动、旋转、删除、撤销；占位校验；角色工位绑定。
- 角色：新增、命名、职责编辑、发型/衣服/肤色/配件；角色档案与运行实例分离。
- 技能：读取本机实际 Skills、搜索和查看说明、按角色配置；在下一次任务中通过真实 skill 输入生效；禁用或失效项明确提示。
- 执行：选择工作目录，启动实际 Codex 任务，显示真实事件、消息和结果；追加指令、停止、处理审批和问题；子 agent 自动成为角色并显示父子关系。
- 成果：完整回复、工具日志、修改文件、打开文件或目录；错误不能显示成成功。
- 持久化：原子保存布局、外观、技能与任务记录；应用重启后恢复，不伪造运行中状态。
- 桌面交付：可启动的 macOS 应用及完整 Godot / bridge 源码，使用说明、验证记录。

实现：Godot 场景/原生 UI + Node.js localhost 桥接 + 本机 Codex App Server。画面仅由可观察状态驱动。展示模式与真实执行明确区分。

验证按风险：Godot 导入和实际窗口检查；地图连通、保存恢复、角色配置、任务状态关键回归；实际 Codex 任务和子 agent 事件验证。避免无关测试和重复覆盖。
